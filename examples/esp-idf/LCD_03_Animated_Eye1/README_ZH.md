# LCD_03_Animated_Eye1

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在两块 LCD 上显示眼睛动画。

## 硬件需求

ESP32-S3-DualEye-LCD-1.28 开发板。

## 怎么运行

在 ESP-IDF 终端打开本目录，版本见 [product.json](../../../.github/product.json)，然后运行：

```bash
idf.py set-target esp32s3 build flash monitor
```
